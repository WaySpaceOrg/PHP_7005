LESSON 04 · EXERCISE 05

Typography และพื้นหลัง ✍️

จัดลำดับและรูปแบบข้อความให้อ่านง่าย

คุณสมบัติสำหรับข้อความ

สี ขนาด น้ำหนัก ระยะบรรทัด และการจัดแนวช่วยกำหนดลำดับความสำคัญและเพิ่มความอ่านง่าย ใช้พื้นหลังหรือเส้นขอบเพื่อแยกเนื้อหาที่เกี่ยวข้อง

หัวข้อที่เห็นชัด

ย่อหน้านี้ใช้สีตัวอักษรที่อ่านง่าย เพิ่มขนาดตัวอักษรและระยะห่างระหว่างบรรทัด เพื่อให้อ่านเนื้อหาภาษาไทยได้สบายตา

หมายเหตุ: ใช้สีพื้นหลังและเส้นขอบเพื่อเน้นข้อมูลสำคัญ โดยยังคงความแตกต่างระหว่างข้อความกับพื้นหลัง

โค้ด CSS ของตัวอย่าง

.text-demo h2 {
  color: #168bb7;
  font-size: 1.8rem;
  line-height: 1.3;
}
.text-demo p {
  color: #354565;
  font-size: 1.08rem;
  line-height: 1.8;
  text-align: justify;
}
.text-demo .note {
  background: #fffdf8;
  border-left: 5px solid #d2a52c;
}

font-size ปรับขนาด, font-weight ปรับความหนา, line-height ปรับระยะบรรทัด และ text-align ปรับแนวข้อความ
