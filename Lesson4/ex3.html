LESSON 04 · EXERCISE 03

Box Model: กล่องและระยะห่าง 📦

จัดขนาดด้วย content, padding, border และ margin

องค์ประกอบของกล่อง

ทุก element เป็นกล่อง: เนื้อหาอยู่ด้านใน ตามด้วย padding, border และ margin ที่สร้างระยะห่างด้านนอก

เนื้อหาของกล่อง
padding อยู่รอบเนื้อหา
.box-model {
  width: 260px;
  padding: 24px;
  border: 8px solid #168bb7;
  margin: 20px auto;
}

ในตัวอย่างนี้ margin: auto ช่วยจัดกล่องให้อยู่กึ่งกลาง ส่วน box-sizing: border-box ทำให้การคำนวณความกว้างรวม padding และ border
