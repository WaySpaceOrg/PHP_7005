LESSON 04 · EXERCISE 06

Pseudo-classes และสถานะการโต้ตอบ 🖱️

เปลี่ยนรูปแบบเมื่อชี้ คลิก หรือเลือกด้วยแป้นพิมพ์

ทดลองสถานะของลิงก์และปุ่ม

ลองเลื่อนเมาส์เหนือปุ่ม กด Tab เพื่อเลื่อนโฟกัส แล้วลองคลิกค้าง Pseudo-class จะเลือก element ตามสถานะ เช่น :hover, :focus-visible และ :active

กลับหน้าแรก

โค้ด CSS

.action-link:hover,
.action-button:hover {
  background: #ffe28a;
}
.action-link:focus-visible,
.action-button:focus-visible {
  outline: 4px solid #168bb7;
  outline-offset: 3px;
}
.action-link:active,
.action-button:active {
  transform: translateY(2px);
}

ควรออกแบบสถานะ focus ให้เห็นชัด เพื่อให้ผู้ใช้ที่นำทางด้วยแป้นพิมพ์รู้ว่ากำลังเลือก element ใด
