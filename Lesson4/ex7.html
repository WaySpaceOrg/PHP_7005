LESSON 04 · EXERCISE 07

Mini Project: Profile Card 🎓

รวม selectors, สี, box model, Flexbox และ responsive design

การ์ดแนะนำตัว

ตัวอย่างนี้รวมสิ่งที่เรียนมา: ใช้ class selectors จัดสีและข้อความ, ใช้ padding/border/radius ทำกล่อง, ใช้ Flexbox จัดวาง และใช้ media query สำหรับหน้าจอเล็ก

🧑🏻‍💻

นักพัฒนาเว็บไซต์

กำลังฝึกสร้างเว็บไซต์ด้วย HTML และ CSS ให้สวยงามและใช้งานได้ทุกขนาดหน้าจอ

HTMLCSSResponsive

ส่วนสำคัญของ CSS

.profile-card {
  display: flex;
  align-items: center;
  gap: 20px;
  padding: 24px;
  border: 2px solid #202b4b;
  border-radius: 18px;
}
@media (max-width: 600px) {
  .profile-card {
    align-items: flex-start;
    flex-direction: column;
  }
}

แบบฝึกหัด: เปลี่ยนข้อความและสีของการ์ด เพิ่มป้ายทักษะอีกหนึ่งรายการ แล้วปรับหน้าต่างให้แคบเพื่อทดสอบ responsive layout
